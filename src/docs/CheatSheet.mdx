# Cheat sheet

Seeing a raw value in a design, like `16px` or `#212529`? Look it up here to find the token to use in
CSS and the key to use in component props. The values are read from the theme and `src/tokens.css`,
so they always match the code.

If a value isn't listed, it isn't on the scale. Check with design before using it.

## Colors

Several tokens can share a hex. Pick the one that matches what you're coloring: `--text-*` for
text, `--bg-*` for backgrounds, `--icon-*` for icons and `--border-*` for borders.
