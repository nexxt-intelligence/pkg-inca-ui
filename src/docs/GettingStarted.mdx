# Getting Started with inca-ui

_Last updated: 2026-10-08_

inca-ui is the shared component library for the inca platform. It wraps
[Mantine](https://mantine.dev) with our theme, design tokens (from Figma), and a set of
custom components.

## 1. Pick the right version

There are two release tracks. **Install the one that matches your app's React version.**

## 2. Set up the provider

Wrap your app once with `CustomMantineProvider`. It sets up the Mantine theme, `ModalsProvider`,
fonts, global CSS, and the design tokens. **Do not** add your own `MantineProvider`.

```tsx
import { CustomMantineProvider } from 'inca-ui';

export const App = () => (
    <CustomMantineProvider>
        <Routes />
    </CustomMantineProvider>
);
```

For white-labeling, pass a 10-shade palette as `brand`. It replaces the `primary` color:

```tsx
<CustomMantineProvider brand={['#f0f9ff', /* ...8 more... */, '#0c4a6e']}>
```

## 3. Import components from `inca-ui`

Always import from `inca-ui`, not from `@mantine/core`.

```tsx
// ✅
import { Button, Group, Stack, Text } from 'inca-ui';

// ❌ skips our wrappers and defaults
import { Button } from '@mantine/core';
```

The package exports three kinds of components:

-   **Extended Mantine components** (`Button`, `TextInput`, `Select`, `Modal`, …): Mantine components with our
    sizes, defaults, and extra props (e.g. `leftIcon="IconPlus"` takes a Tabler icon name).
    Check each component's story for the props it supports.
-   **Custom components** (`ActionCard`, `ChatInput`, `SplitButton`, `MiniModal`, …).
-   **Re-exported Mantine components** (`Group`, `Stack`, `Flex`, `Box`, `Paper`, `Popover`, …): used as-is.

If you need a component that isn't exported, ask in the team channel or add it here first instead of
importing it from Mantine directly.

## 4. Design tokens

All tokens are CSS variables defined in `src/tokens.css`. They are available globally once the provider
is mounted.

**Rules**

1. Use semantic tokens (`--text-subtle`, `--bg-accent`, …) for colors.
2. **Never** use raw hex values or Mantine internals like `var(--mantine-color-blue-6)`.
3. Use the spacing / radius / font-size scales. Don't hardcode `px` values that aren't on the scale.

### Colors

Tokens are named `--{category}-{role}`. Pick by **what the color is used for**, not by how it looks.

## 5. Using tokens in code

**In component props**, use the Mantine scale keys for spacing/radius/size and `var(--token)` for colors:

```tsx
<Stack gap="xs" p="md">
    <Text c="var(--text-subtle)" size="sm">
        Last edited 2 days ago
    </Text>
    <Group gap="2xs">
        <Icon color="var(--icon-accent)" type="IconSparkles" />
        <Text c="var(--text-ai)">AI suggestion</Text>
    </Group>
</Stack>
```

**In CSS modules** (preferred for anything more than a couple of props), use the CSS variables:

```css
/* MyCard.module.css */
.root {
    padding: var(--spacing-md);
    border: 1px solid var(--border-default);
    border-radius: var(--radius-md);
    background: var(--bg-surface);
    box-shadow: var(--shadow-1);
}

.root:hover {
    background: var(--bg-hover);
}

.caption {
    color: var(--text-subtle);
    font-size: var(--font-size-xs);
}
```

```css
/* ❌ Avoid */
.root {
    padding: 15px; /* not on the scale */
    color: #868e96; /* raw hex */
    border-color: var(--mantine-color-gray-2); /* Mantine internal */
}
```

### Mantine 6 vs 9 differences

If you're on `v7` (`inca-ui@legacy`), tokens and component names are the same, but some props follow

## 6. Contributing

1. Make the change on both `main` and `v7` (separate branches and PRs, each with its own changeset).
2. Run `yarn storybook` and add/update the component's `*.stories.tsx`.
3. Use tokens in your CSS modules (see above).
4. Run `yarn changeset` (patch or minor only, never major) and commit the generated file with your PR.
5. After merge, a **Version Packages** PR is opened automatically. Merging it publishes to npm.

See the [README](https://github.com/nexxt-intelligence/pkg-inca-ui#readme) for release details.
